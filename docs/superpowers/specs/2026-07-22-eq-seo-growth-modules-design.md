# EQ SEO 增长模块设计

## 目标

把 HighEQ 从“高情商回复生成器”升级为“AI 情商沟通测试、训练与实战助手”。本次设计新增三个公开 SEO 模块：TalkType 沟通人格测试、情商急诊室、高情商评分器。它们共同承担游客获客、首次体验、注册转化和订阅付费验证。

整体漏斗：

```text
SEO 搜索访问
  -> TalkType 测试 / 评分器 / 急诊室
  -> 免费获得有趣或有用结果
  -> 注册保存报告、继续诊断或解锁深度分析
  -> Free 额度触顶或高级能力被锁定
  -> Lite / Pro 订阅
```

## 理论与内容来源边界

TalkType 沟通人格测试参考成熟情商理论框架，但不复制商业量表题目、题干或评分规则。题目与结果说明必须原创，以生活、恋爱、朋友、家人和职场沟通场景表达。

可参考的公开框架：

- Daniel Goleman 情商四域：Self Awareness、Self Management、Social Awareness、Relationship Management。
- Mayer-Salovey 能力模型：感知情绪、运用情绪促进思考、理解情绪、管理情绪。
- SSEIT 结构：33 项自评量表，常用于测量总体情商能力。
- TEIQue 结构：特质情商自评框架，包含全局分、因素和细分面向。

产品内文案需要明确：测试结果用于自我了解和沟通训练，不等同于医学、心理诊断或正式人才测评。

## 用户画像

### 情绪关系型用户

典型用户是恋爱、朋友、家庭关系中容易纠结回复的人。他们关心“对方是不是不高兴了”“我怎么解释才不伤感情”“这句话该不该发”。最容易被情商急诊室和 TalkType 测试吸引。

付费触发点是深度潜台词分析、多版本回复、人物档案联动和真实聊天诊断历史。

### 职场表达型用户

典型用户是职场新人、销售、客服、运营、项目经理。他们需要回复领导、催同事、安抚客户、拒绝不合理需求。最容易被高情商评分器和职场场景急诊吸引。

付费触发点是职场专项题库、真实回复评分、专业改写、模板和高额度。

### 自我成长型用户

典型用户喜欢 MBTI、人格测试、心理测试、沟通能力提升。他们愿意为了“我是什么类型”而完成测试，也更容易分享结果页。

付费触发点是完整报告、四维雷达图、训练计划、成长曲线。

### 高频实用型用户

典型用户每天有大量沟通任务，需要更快生成、更稳定复用和更高额度。他们会从游客模块进入，但最终使用历史、收藏、人物档案和正式生成器。

付费触发点是额度、素材库、人物档案、截图诊断、多轮改写。

## 模块一：TalkType 沟通人格测试

### 产品定位

SEO 主入口和分享入口。对外传播名是 `TalkType 沟通人格测试`，SEO 文案仍覆盖“情商测试”“EQ 测试”“高情商人格测试”等关键词。所有游客都可以完成完整 24 道场景题，不用登录、不分轻量版和完整版。测试结果不是单纯总分，而是根据 S/W/B/C 四维沟通画像匹配 12 种鲜明人格。

### 页面

URL：`/eq-test`

页面标题建议：`TalkType 沟通人格测试 - 测出你的高情商人格类型`

Meta description 建议：`通过 24 道真实沟通场景选择题，测出你的 TalkType 高情商沟通人格、四维沟通代码和专属表达盲区。`

### 维度

TalkType 使用 4 个可解释维度。每个维度最终归一化为 0 到 100 分。

| 代码 | 维度 | 高分倾向 | 低分倾向 |
| --- | --- | --- | --- |
| S | 情绪洞察 Sensitivity | 很会读空气、看潜台词、捕捉情绪变化 | 更关注字面信息和事情本身 |
| W | 表达温度 Warmth | 说话柔和、有照顾感、善于安抚 | 表达直接、效率优先、少铺垫 |
| B | 边界稳定 Boundary | 能守住自己，不容易被拿捏 | 容易迁就、怕关系破裂 |
| C | 局势掌控 Control | 冲突中能控场、修复、推进 | 容易被情绪或场面带走 |

### 题型

第一版使用 24 道原创场景选择题，每题 4 个选项。每个选项为 S/W/B/C 四个维度分配 0 到 3 分，不直接给人格。题目必须避免“非常同意/非常不同意”的学术量表感，改为生活化选择。

示例：

```text
对方回你：“随便你吧。”
你会怎么处理？

A. 那我就按自己的想法来
S +0 / W +0 / B +2 / C +1

B. 追问：“你是不是不太开心？”
S +3 / W +2 / B +0 / C +1

C. 先安抚：“我感觉你可能有点不舒服，我不是想忽略你的想法”
S +3 / W +3 / B +1 / C +2

D. 先停一下，等对方情绪过去再沟通
S +2 / W +1 / B +2 / C +1
```

### 评分与人格匹配

每道题的四维分相加后，按该维度可获得的最高分归一化为 0 到 100。总分只作为“沟通成熟度”展示，不用于直接决定人格。

人格匹配采用最近中心点算法：

```text
用户四维分数 [S, W, B, C]
  -> 与 12 个 TalkType 人格中心点分别计算加权距离
  -> 距离最近的人格为主结果
  -> 距离第二近的人格作为副倾向
```

默认四维权重相同。若两个结果距离差小于 5%，展示“主类型 + 副倾向”，例如：`高敏雷达型，带一点情绪翻译官倾向`。

| --- | ---: | ---: | ---: | ---: | --- |

| 温柔灭火器 | 80 | 92 | 45 | 78 | 冲突里优先降温，擅长安抚，但可能为了和气牺牲自己 |

| 冷静谈判家 | 62 | 60 | 86 | 92 | 职场和复杂沟通中稳定、有分寸，能推进问题解决 |

## 模块二：情商急诊室

### 产品定位

真实聊天问题的即时诊断入口。它的吸引力不是“帮你生成一句回复”，而是“帮你看懂这段聊天现在发生了什么”。

### 页面

URL：`/eq-emergency`

页面标题建议：`情商急诊室 - 上传聊天截图，AI 诊断怎么高情商回复`

Meta description 建议：`粘贴聊天记录或上传聊天截图，AI 帮你分析当前气氛、对方潜台词、误会风险和推荐回复策略。`

### 输入

- 聊天文本，必填其一。
- 聊天截图，必填其一；第一版可复用现有 OSS 上传与视觉模型能力。
- 场景：恋爱、朋友、家人、职场、客户、陌生人。
- 我的目标，可选：缓和气氛、解释原因、拒绝请求、表达边界、挽回关系、推进事情。

### 输出

基础诊断：

- 当前气氛。
- 误会风险：低、中、高。
- 对方潜台词。
- 当前风险点。
- 推荐沟通策略。

回复处方：

- 稳妥版。
- 温柔版。
- 坚定版。
- 高情商反转版，Pro 可见。

### 付费边界

Free：

- 每日 1 次基础诊断。
- 文本诊断。
- 2 条回复建议。

Lite：

- 更多诊断次数。
- 支持截图诊断。
- 3 条回复建议。
- 保存诊断历史。

Pro：

- 深度潜台词分析。
- 高情商反转版。
- 多轮追问。
- 人物档案联动。
- 诊断结果转正式生成器继续改写。

## 模块三：高情商评分器

### 产品定位

互动训练和留存入口。系统给随机场景，用户先写回复，再由 AI 分析、评分、指出优缺点，并给出优化版本。

### 页面

URL：`/eq-score`

页面标题建议：`高情商评分器 - 测测你的回复能得多少分`

Meta description 建议：`随机抽取聊天、恋爱、朋友和职场沟通场景，输入你的回复，AI 分析高情商程度、指出优缺点，并给出优化后分数。`

### 玩法

系统随机给出：

- 场景分类。
- 对方身份。
- 对方说的话。
- 用户目标。

用户输入回复后，AI 返回：

- 情商分。
- 水平标签。
- 优点。
- 缺点。
- 改进建议。
- 优化后回复。
- 预计提升分数。

### 题库分类

- 恋爱沟通。
- 朋友关系。
- 家人关系。
- 回复领导。
- 同事协作。
- 客户沟通。
- 拒绝请求。
- 道歉修复。
- 催办提醒。
- 边界表达。

第一版使用前端静态题库，至少 30 道场景。后续可迁移到后端表，支持运营配置和热门场景统计。

### 付费边界

Free：

- 每日 3 次评分。
- 随机题。
- 基础评分结果。

Lite：

- 更多评分次数。
- 分类题库。
- 完整扣分原因。
- 保存评分记录。

Pro：

- 真实场景评分。
- 高级改写建议。
- 成长曲线。
- 专项训练计划。

## 验收标准

- 游客可以从三个公开 URL 直接使用对应基础能力。
- 每个页面都有独立 SEO meta、H1、FAQ 和内链。
- TalkType 测试不复制成熟量表题目，题目和结果说明为原创内容。
- TalkType 人格不是随机分配，也不是按总分分配；必须由 S/W/B/C 四维分数与 12 种人格中心点匹配得出。
- 游客可以完成全部 24 道 TalkType 测试题并查看完整基础结果。
- 高情商评分器返回结构化评分、优缺点、改进建议和提升分数。
- 情商急诊室返回结构化诊断、风险、策略和回复处方。
- 免费结果页都有自然的注册或订阅引导。
- 订阅权益能解释为“更准、更深、更个性化”，而不只是更多次数。

## 非目标

- 不做正式心理诊断。
- 不承诺测试结果具备临床或招聘测评效力。
- 第一版不建设复杂运营后台题库。
- 第一版不要求三个模块全部保存历史。
- 第一版不做社交平台一键分享，只保留可复制分享文案。

## 自审记录

- 无占位词或未完成标记。
- 三个模块都围绕 SEO 游客入口和订阅闭环，没有拆成互相孤立的功能。
- 题库来源边界明确，避免照搬商业量表。
- TalkType 已改为完整开放测试，并通过四维中心点匹配保证人格结果有可解释逻辑。
- 第一版范围控制为可在现有 HighEQ 前后端结构内落地。
